This computer is a Hackboard2.  Currently there is no way to interact with the GPIO pins in Windows.  This project is to research the board to determine how to build GPIO access.  You have unlimited access to this computer to conduct the research.  Installed on the computer is Python and the .NET 10 SDK.  Python is probably the right choice for testing and development.  The ultimate goal is to make GPIO access available to .NET applications.  Python could be the bridge for that or we could develop a .NET library in C# for GPIO access.  We do not have to decide that approach now - this is the research and information gathering phase.  Please work in the Research folder of this project.  In the folder you will find a text file with the GPIO pin mapping information that came with the board.  This is the only information I have.  Some have said that the Linux versions of the board came with python libraries to access the pins.  I have not confirmed that.  You are free to research on the internet.  Start with asking me any questions and then building a plan for the research phase and a draft overall plan to the final goals of the project.  Also please update the readme.md in the root folder for GitHub and create a .gitignore file there with initial configuration relevant to this project.
